# Portafolio de Andres Lopez

Sitio estatico para presentar los proyectos principales de `ennigmatico`.

## Abrir localmente

Abre `index.html` en el navegador.

## Publicar en GitHub Pages

1. Sube esta carpeta a un repositorio publico, por ejemplo `portfolio`.
2. En GitHub entra a `Settings > Pages`.
3. En `Build and deployment`, elige `Deploy from a branch`.
4. Selecciona `main` y la carpeta `/root`.
5. Guarda los cambios.

GitHub generara una URL publica para compartir el portafolio.
